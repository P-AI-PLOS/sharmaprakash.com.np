# Building My Homelab illustrations

`network.svg` and `services.svg` are publication snapshots copied from
`/Users/prakash/workspaces/2026/homelab/docs/network/`. Their device illustrations
are original schematic artwork. They are deliberately frozen for the September
article; future inventory changes do not silently change that article's baseline.

The publication views include Titan as a standalone macOS utility host on
Trusted Wi-Fi, outside both XCP-ng pools. The purple dashed link represents
wireless membership, not a wired speed or a pinned AP association. Quinjet
appears above ground-floor Sanctuary as a floor-location reminder. The
`clamshell-laptop.svg` asset is the original Titan device illustration.

`upgrade.svg` is generated by `scripts/images/render-homelab-upgrade.mjs` using
the local `assets/` illustrations copied from the homelab diagram assets.
Edit the renderer for layout and content changes, then run
`node scripts/images/render-homelab-upgrade.mjs` before regenerating its PNG.
Link colors are blue for 10G, teal for 2.5G and amber for 1G.
Both AP uplinks use amber with a `1G max` label, based on the official
[U6-LR specifications](https://techspecs.ui.com/unifi/wifi/u6-lr) and
[AC Pro specifications](https://techspecs.ui.com/unifi/wifi/uap-ac-pro).
These are hardware limits, not fresh live negotiated-speed checks.
Each compute host has its own colored cable from the switch. Speed labels preserve meaning
without relying on color alone. This is an original palette, not a UniFi
product screenshot or an official vendor legend.

The topology is for the October article, commissioned
before installation and showing the requested completed configuration. It is
not evidence of deployed hardware. It assumes a compatible NAS 10G adapter and
interconnect; exact parts and installation acceptance remain unverified.

The articles use the requested technical diagrams as featured images. The PNG
versions provide raster images for social previews. Regenerate them with:

```sh
rsvg-convert -o public/images/blog/building-my-homelab/network.png public/images/blog/building-my-homelab/network.svg
rsvg-convert -o public/images/blog/building-my-homelab/upgrade.png public/images/blog/building-my-homelab/upgrade.svg
```

The user-supplied inspiration screenshot is not a publication asset and is not
copied into this site.
